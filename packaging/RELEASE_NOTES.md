## Instalar (Windows 10/11)

1. Baixe o **`AirMouse-Setup-<versão>.exe`** abaixo, em *Assets*, e abra o arquivo.
2. O Windows deve avisar "O Windows protegeu o computador", porque o instalador ainda não tem assinatura digital. Clique em **Mais informações → Executar assim mesmo**.
3. Avance as telas. O AirMouse abre e mostra no navegador um guia de primeiros passos: escolher a câmera, a mão do mouse e um treino rápido com a sua mão.

Não precisa de Python nem de administrador. O AirMouse fica no ícone ao lado do relógio: clique nele para abrir os ajustes. **Sem webcam?** Um app que transforma o celular em webcam, como DroidCam ou Iriun, aparece como uma câmera comum.

**Como usar:** mão parada não faz nada. Segure de 1 a 5 dedos parados para ligar um modo (1 mover, 2 rolar, 3 atalhos, 4 mídia; para 5 janelas, feche a mão e depois abra). Feche a mão para pausar e segure fechada para desligar.

## Install (Windows 10/11)

Download **`AirMouse-Setup-<version>.exe`** from *Assets* below and run it. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: choose **More info → Run anyway**. AirMouse installs for your user only (no Python, no administrator prompt) and opens a setup guide in your browser.
